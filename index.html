A FEW THINGS YOU MIGHT BE WONDERING

Do I need to know how to code?+

You can start by explaining what you want in plain language. The agent can handle the code and deployment; your role is to review the result and guide the decisions. Account access or approvals may still need your involvement.

Can I change it after it’s published?+

Yes. Open the project in Codex, describe your change, and ask the agent to update, verify, commit, and push it. GitHub Pages rebuilds the published site from the main branch.

What’s actually running this website?+

Just HTML, CSS, and JavaScript. No build system, subscription service, or database is needed for this demo. The complete source is available in the linked GitHub repository.
